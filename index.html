01 / Developer toolRepository available

FrostFlow — Website QA Automation

A quality-assurance audit engine designed for freelancers, small agencies, and non-technical founders. A user submits a website URL and receives a report of issues found during automated checks.

Problem

Manually checking client websites for broken links, navigation issues, and other defects takes time and can miss problems.

Approach

Built a web app and a separate scan worker. The worker uses Playwright to crawl pages and run browser checks; jobs are queued and results are stored for reporting.

Engineering

Project architecture includes a React frontend, Node.js APIs, Fastify worker, PostgreSQL with Prisma, Redis with BullMQ, and Gemini-assisted report generation.

03 / Technical experimentExploration

Digital Twin Room

An experiment around converting a photo of a room into an interactive 3D scene. The concept explores object detection and constructing a scene with Three.js.

Problem

Turning a static room image into a scene that can be explored and modified in 3D is a challenging computer-vision and rendering workflow.

Exploration

Investigating how detected objects and room elements could be represented as objects in a 3D environment.

Focus

Learning the integration between image understanding, scene structure, and browser-based 3D rendering.
